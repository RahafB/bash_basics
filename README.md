# Bash & Git Coursework

**Educational exercises in shell scripting, command-line tools, and Git branching.**

This repository is a coursework collection based on teaching materials originally copied from **Tacksoo Im**. It includes shared starter examples, my assignment work, and screenshots recording Git exercises. The entire collection should not be interpreted as independently authored software.

## What's here

- Numbered scripts introducing input, arithmetic, conditionals, and loops.
- [basics.sh](basics.sh), [git.sh](git.sh), and [regex.sh](regex.sh) for shell, Git, and regular-expression examples.
- [Joshua Wilson/joshua.sh](Joshua%20Wilson/joshua.sh) for my named assignment contribution.
- Branch and merge screenshots documenting the coursework workflow.

## Explore an individual script

Use Bash on Linux, macOS, or an appropriate shell environment:

```bash
bash -n "Joshua Wilson/joshua.sh"
bash "Joshua Wilson/joshua.sh"
```

`bash -n` checks syntax without executing the script. Read a script before running it; these teaching files cover different commands and are not intended to be launched as one application. The infinite-loop example must be stopped with `Ctrl+C`.
